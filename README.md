# Recall

Офлайн-приложение для запоминания информации с помощью карточек и интервального повторения (алгоритм SM-2). Подробнее об идее — в [VISION.md](docs/VISION.md).

## Стек

- Kotlin
- Jetpack Compose, Material 3
- Navigation Compose (type-safe маршруты)
- ViewModel + StateFlow (однонаправленный поток данных)
- Kotlin Coroutines и Flow
- Room (KSP) — хранение колод, карточек и прогресса
- DataStore — пользовательские настройки (опционально)
- Ручной DI через `AppContainer`
- JUnit — юнит-тесты алгоритма повторения и ViewModel

## Экраны

1. **Список колод** — все колоды с количеством карточек и числом карточек к повторению сегодня.
2. **Колода** — список карточек колоды и кнопка запуска повторения.
3. **Редактирование карточки** — создание новой или изменение существующей карточки.
4. **Повторение** — показ карточек по одной с оценкой ответа.

## Пользовательские сценарии и критерии готовности

### 1. Управление колодами

Пользователь создаёт колоды, чтобы разделить материал по темам.

- [ ] Можно создать колоду, указав название.
- [ ] Нельзя создать колоду с пустым названием.
- [ ] Можно переименовать колоду.
- [ ] Можно удалить колоду после подтверждения; вместе с ней удаляются все её карточки.
- [ ] В списке у каждой колоды отображается общее число карточек и число карточек к повторению сегодня.
- [ ] Если колод нет, показывается пустое состояние с подсказкой, как создать первую.

### 2. Управление карточками

Пользователь наполняет колоду карточками «вопрос — ответ».

- [ ] Можно добавить карточку с лицевой стороной (вопрос) и обратной (ответ).
- [ ] Нельзя сохранить карточку, если хотя бы одно поле пустое.
- [ ] Можно отредактировать текст карточки; прогресс её изучения при этом сохраняется.
- [ ] Можно удалить карточку.
- [ ] Новая карточка сразу доступна для повторения.
- [ ] Если в колоде нет карточек, показывается пустое состояние с подсказкой.

### 3. Повторение

Пользователь повторяет карточки, срок которых наступил.

- [ ] Повторение запускается с экрана колоды и включает только карточки, срок повторения которых наступил.
- [ ] Сначала показывается вопрос; ответ открывается по нажатию «Показать ответ» (с анимацией переворота карточки).
- [ ] После показа ответа доступны четыре оценки: «Снова», «Трудно», «Хорошо», «Легко».
- [ ] Отображается прогресс сессии, например «3 / 12».
- [ ] После последней карточки показывается экран завершения с числом повторённых карточек.
- [ ] Если повторять нечего, пользователь видит сообщение «На сегодня всё» вместо пустого экрана.
- [ ] Быстрое двойное нажатие на оценку не приводит к двойной оценке одной карточки.

### 4. Интервальное повторение

Приложение планирует, когда показать карточку снова.

- [ ] После каждой оценки дата следующего повторения пересчитывается по алгоритму SM-2.
- [ ] Оценка «Снова» сбрасывает прогресс карточки, и она показывается снова в ближайшее время.
- [ ] Чем выше оценка, тем больше интервал до следующего показа.
- [ ] Алгоритм реализован как чистый Kotlin-код без зависимостей от Android и покрыт юнит-тестами.

### 5. Сохранение данных

- [ ] Колоды, карточки и прогресс повторения сохраняются между запусками приложения.
- [ ] Поворот экрана не сбрасывает введённый текст, открытый ответ и прогресс сессии.
- [ ] После закрытия приложения системой (смерть процесса) уже оценённые карточки не попадают в очередь повторно.
- [ ] Каждая оценка сохраняется в базу сразу, а не в конце сессии.

## Общие критерии готовности

- [ ] Приложение собирается из репозитория без дополнительной настройки.
- [ ] Все сценарии выше выполняются без падений.
- [ ] Поддерживаются светлая и тёмная темы.
- [ ] У основных экранов есть `@Preview` для stateless-компонентов.
- [ ] Проверено поведение при включённой опции «Don't keep activities».

## Возможные расширения (если останется время)

- Настройка дневного лимита карточек (DataStore).
- Возврат карточки с оценкой «Снова» в конец текущей сессии.
- Экран статистики: повторения по дням, число выученных карточек.
- Импорт колоды из CSV-файла.
- Ежедневное напоминание о повторении (WorkManager).

## Сборка и запуск

1. Клонировать репозиторий.
2. Открыть проект в Android Studio.
3. Запустить конфигурацию `app` на эмуляторе или устройстве (Android 8.0+).

Запуск юнит-тестов:

```bash
./gradlew test
```
